# nexusClient

Неофициальная модифицированная сборка на базе [BestClient](https://github.com/BestProjectTeam/BestClient) и [DDNet](https://github.com/ddnet/ddnet), Windows x64.

[Скачать последнюю версию](https://github.com/Misha123a/nexusClient/releases/latest)

## Что сделано

- Убрана проверка доступа по IP.
- Исправлено падение при запуске из-за настройки соотношения сторон.
- Добавлены 48 заменяющих иконок меню.
- Убраны лишние EXE, сервер и обновлятор BestClient из комплекта.

## Как запустить

1. Скачайте ZIP из Releases и полностью распакуйте его.
2. Запустите **Start-nexusClient.cmd** — он отключает motion blur при запуске.
3. **Insert (Ins)** открывает и закрывает меню модификаций.
4. **При первом запуске может понадобиться нажать Escape (Esc).**

**Motion blur не работает корректно: вызывает пикселизацию. Не включайте его.** При запуске `nexusClient.exe` напрямую отключите эффект через F1 командой `bc_motion_blur 0`.

## О сборке

Это модификация готового EXE; исходники этой конкретной модификации в репозитории не представлены. Ресурсы и библиотеки взяты из BestClient v3.1.1. Заменяющие иконки — [Lucide](https://github.com/lucide-icons/lucide); лицензия включена в архив. Уведомления о лицензиях исходного комплекта сохранены в `license.txt` и папке `data`.
